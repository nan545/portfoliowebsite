# Webnex Technologies

A responsive React and Vite portfolio for Webnex Technologies.

## Development

```sh
npm install
npm run dev
```

## Build and checks

```sh
npm run lint
npm run build
```

Project previews are sample concepts. Replace the project data in
`src/components/Sections.jsx` with Webnex's own work when available. Update
the contact placeholders and connect the form to a submission service before
launching.
