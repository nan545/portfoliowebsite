# Webnex Technologies

A responsive React and Vite portfolio for Webnex Technologies.

## Development

```sh
npm install
npm run dev
```

## Build and checks

```sh
npm run lint
npm run build
```

## Deployment

The GitHub Actions workflow deploys the site to GitHub Pages when changes are
pushed to `main`. In the repository settings, open **Pages** and set the
deployment source to **GitHub Actions**. After the first successful workflow,
the site will be available at:

<https://nan545.github.io/portfoliowebsite/>

Project previews are sample concepts. Replace the project data in
`src/components/Sections.jsx` with Webnex's own work when available. Update
the contact placeholders and connect the form to a submission service before
launching.
